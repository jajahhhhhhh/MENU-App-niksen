## The one rule

Advertise only what the till can ring up. Check
`https://niksensamui.com/api/public/menu` before any claim about the menu goes
out. Everything in this folder spent a month promising coffee, bowls,
breakfasts and five island teas, none of which the shop sells.

For anything involving the bar: no prices, no brands, no promotions. See
`content-plan.md` §6.
